ctDNA summary

Outstanding ctDNA orders (any status other than "completed") ordered within the date range below, plus orders completed within that same range, split by managing organisation (resolved from ServiceRequest.requester — either an Organization directly, or the Organization referenced by a PractitionerRole requester), shown with its NHS ODS code where the Organization resource has one. "Test code" is the coding under https://fhir.nhs.uk/CodeSystem/England-GenomicTestDirectory specifically (not its display text, and not any other coding the same CodeableConcept might carry). ctDNA orders are identified by a best-effort text match on the order's test code text, since this IG has no single confirmed code for ctDNA testing — see _is_ctdna_order() in fhir_client.py if this needs tightening for your server. "iGene report ID" is the identifier carried under the https://fhir.nwgenomics.nhs.uk/iGene/ReportIdentifier system, checked on the order first and then the report.
