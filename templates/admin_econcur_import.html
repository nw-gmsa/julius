econcur import

Imports NHS ODS's econcur.csv export ("English Hospital Consultants" — NHS Digital: ODS CSV downloads) as Practitioner + PractitionerRole resources on this FHIR server. Matches existing entries by GMC number, so re-running this doesn't create duplicates — but Practitioner and Organization are create-only: once one exists it's never rewritten, even if econcur.csv's data for it has since changed. A location organisation code with no matching Organization on this server gets a minimal stub one created (ODS code only, no name) rather than the row being skipped. PractitionerRole is created with a composite GMC+ODS identifier plus an identifier on each of its practitioner/organization references; once a role carries all three it's likewise never updated again — see FhirClient.import_econcur() for the exact rules.
